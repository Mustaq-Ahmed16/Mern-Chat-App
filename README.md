# Mern-Chat-App
Some Features:

🌟 Tech stack: MERN + Socket.io + TailwindCSS + Chakra UI
🎃 Authentication && Authorization with JWT
👾 Real-time messaging with Socket.io
🚀 (Socket.io and React Context)
🐞 Error handling both on the server and on the client
⭐ At the end Deployment

### Setup .env file

```js
PORT=...
MONGO_DB_URI=...
JWT_SECRET=...
NODE_ENV=...
```

### Build the app

```shell
npm run build
```

### Start the app

```shell
npm start
```
